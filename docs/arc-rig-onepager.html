The arc is a good instrument; the map it draws is the room. Below 3 kHz the hub loudspeaker is a valid axisymmetric source, and from 3–5 kHz it is not.

0.21 dB of the position map is provably the rig — antisymmetric under the flip
1.04 dB is provably the room; the 0.84 dB a single flip cannot divide is room too (cov = −0.09 dB², CI [−0.22, +0.03])
≤ 0.16 dB is all the two geometries share — so the rig's total contribution is ~0.2 dB

How the capsules were calibrated

Substitution, 2026-09-16. Each of the eleven was measured in turn at the same seat, one capsule and one speaker in a cleared chamber, so differencing any two cancels source, room and analog chain exactly — the source only has to hold still. 97 tones, 62 Hz–16 kHz at 12/octave, amplitude 0.03, 48 kHz, 2 s per tone and 6 s below 250 Hz; every capsule's Mic Capture Volume gated at unity first. All 55 pairs follow from the eleven captures. Drift bracket: 810-8904 was re-measured at the end — −0.025 dB mean, 0.165 sd over 2 h 13 min (0.09 dB sd below 1 kHz, 0.24 above 4 kHz), which is what licenses the method. Seven of eleven factory files were wrong by 0.6–3.6 dB. The datum is the four whose certificates agree with each other and with measurement (810-8900, 810-8903, 811-1896, 811-2321), not the group mean, because the error is batch-correlated. Corrections went into cal.gain_db only, held flat outside 90 Hz–16 kHz; Sens Factors kept verbatim. Acceptance: the spread across the eleven fell 4.01 → 0.02 dB. Normal incidence only, which matches the arc. No absolute anchor — the method is blind to error common to all eleven, and only a 94 dB calibrator closes that.

Open, and where the data is

The loudspeaker map does not reproduce the propeller map (r = −0.04 tone-notched, +0.04 mixed; all 22 relabellings tested, best +0.24) — the propeller's own inflow, or the object at the hub, still matters. Room geometry is unrecorded: hub height, room L×W×H, foam, what stands near the arc ends. Nothing above 6350 Hz has been measured with the arc.
